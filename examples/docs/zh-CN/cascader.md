## Cascader 级联选择器

当一个数据集合有清晰的层级结构时，可通过级联选择器逐级查看并选择。

### 基础用法

有两种触发子菜单的方式

:::demo 只需为 Cascader 的`options`属性指定选项数组即可渲染出一个级联选择器。通过`props.expandTrigger`可以定义展开子级菜单的触发方式。
```html
<div class="block">
  <span class="demonstration">默认 click 触发子菜单</span>
  <hzq-cascader
    v-model="value"
    :options="options"
    @change="handleChange"></hzq-cascader>
</div>
<div class="block">
  <span class="demonstration">hover 触发子菜单</span>
  <hzq-cascader
    v-model="value"
    :options="options"
    :props="{ expandTrigger: 'hover' }"
    @change="handleChange"></hzq-cascader>
</div>
```

### 动态加载

当选中某一级时，动态加载该级下的选项。

:::demo 通过`lazy`开启动态加载，并通过`lazyload`来设置加载数据源的方法。`lazyload`方法有两个参数，第一个参数`node`为当前点击的节点，第二个`resolve`为数据加载完成的回调(必须调用)。为了更准确的显示节点的状态，还可以对节点数据添加是否为叶子节点的标志位 (默认字段为`leaf`，可通过`props.leaf`修改)，否则会简单的以有无子节点来判断是否为叶子节点。
```html
<hzq-cascader :props="props"></hzq-cascader>

<script>
  let id = 0;

  export default {
    data() {
      return {
        props: {
          lazy: true,
          lazyLoad (node, resolve) {
            const { level } = node;
            setTimeout(() => {
              const nodes = Array.from({ length: level + 1 })
                .map(item => ({
                  value: ++id,
                  label: `选项${id}`,
                  leaf: level >= 2
                }));
              // 通过调用resolve将子节点数据返回，通知组件数据加载完成
              resolve(nodes);
            }, 1000);
          }
        }
      };
    }
  };
</script>
```

### 自定义搜索建议项

:::demo 搜索模式下可以用 `suggestion` 作用域插槽自定义每个建议项的内容，作用域参数为 `{ item, index, keyword }`：`item` 是扁平化后的节点（含 `text`、`path`、`data` 等字段），`keyword` 是当前搜索关键词。插槽只替换建议项内部的内容，点击选中与勾选标记仍由组件处理，下方示例做了关键词高亮。
```html
<hzq-cascader
  placeholder="试试搜索：指南"
  :options="options"
  filterable>
  <span slot="suggestion" slot-scope="{ item, keyword }" class="cascader-demo-suggestion">
    <template v-for="(part, i) in highlight(item.text, keyword)">
      <span :key="i" :class="{ 'cascader-demo-suggestion__hit': part.hit }">{{ part.text }}</span>
    </template>
    <i v-if="item.checked" class="hzq-icon-check"></i>
  </span>
</hzq-cascader>

<script>
  export default {
    data() {
      return {
        options: [{
          value: 'zhinan',
          label: '指南',
          children: [{
            value: 'shejiyuanze',
            label: '设计原则',
            children: [
              { value: 'yizhi', label: '一致' },
              { value: 'fankui', label: '反馈' }
            ]
          }, {
            value: 'daohang',
            label: '导航',
            children: [
              { value: 'cexiangdaohang', label: '侧向导航' },
              { value: 'dingbudaohang', label: '顶部导航' }
            ]
          }]
        }, {
          value: 'zujian',
          label: '组件',
          children: [{
            value: 'basic',
            label: 'Basic',
            children: [
              { value: 'button', label: 'Button 按钮' },
              { value: 'cascader', label: 'Cascader 级联选择器' }
            ]
          }]
        }]
      };
    },
    methods: {
      // 把文本按关键词切成普通片段与命中片段
      highlight(text, keyword) {
        if (!keyword) return [{ text, hit: false }];
        const parts = [];
        const lowerText = text.toLowerCase();
        const lowerKeyword = keyword.toLowerCase();
        let start = 0;
        let index = lowerText.indexOf(lowerKeyword);
        while (index > -1) {
          if (index > start) parts.push({ text: text.slice(start, index), hit: false });
          parts.push({ text: text.slice(index, index + keyword.length), hit: true });
          start = index + keyword.length;
          index = lowerText.indexOf(lowerKeyword, start);
        }
        if (start < text.length) parts.push({ text: text.slice(start), hit: false });
        return parts;
      }
    }
  };
</script>
```

### change 事件取到原始节点

:::demo `change` 的第二参 `nodes` 是当前选中节点对应的**原始 option 数组**，可直接取业务字段，不必再按 value 反查。单选返回 `[option]`，多选返回各选中节点的 option 数组，无选中或清空时为 `[]`。
```html
<template>
  <div>
    <hzq-cascader
      v-model="value"
      :options="options"
      :props="{ multiple: true }"
      @change="handleChange"></hzq-cascader>
    <span class="demonstration">当前选中的商品 id：{{ goodsIds.join(', ') || '无' }}</span>
  </div>
</template>

<script>
  export default {
    data() {
      return {
        value: [],
        goodsIds: [],
        options: [{
          value: 'drink',
          label: '饮品',
          children: [{
            value: 'coffee',
            label: '咖啡',
            goodsId: 1001,
            children: [
              { value: 'latte', label: '拿铁', goodsId: 1002 },
              { value: 'mocha', label: '摩卡', goodsId: 1003 }
            ]
          }]
        }, {
          value: 'snack',
          label: '零食',
          children: [
            { value: 'cookie', label: '饼干', goodsId: 2001 }
          ]
        }]
      };
    },
    methods: {
      handleChange(value, nodes) {
        // nodes 里就是原始 option，业务字段直接取

      }
    }
  };
</script>
```

### remove-tag 取到被移除的值与下标

:::demo 多选移除 Tag 时，`remove-tag` 的第二参是该 Tag 在**已展示标签**中的下标。配合 `collapse-tags` 时，下标对应的是当前可见的 Tag 顺序。
```html
<template>
  <div>
    <hzq-cascader
      v-model="value"
      :options="options"
      :props="{ multiple: true }"
      @remove-tag="handleRemoveTag"></hzq-cascader>
    <span class="demonstration">刚移除：{{ removed.text || '无' }}（下标 {{ removed.index }}）</span>
  </div>
</template>

<script>
  export default {
    data() {
      return {
        value: [['zhejiang', 'hangzhou'], ['zhejiang', 'ningbo']],
        removed: { text: '', index: -1 },
        options: [{
          value: 'zhejiang',
          label: '浙江',
          children: [
            { value: 'hangzhou', label: '杭州' },
            { value: 'ningbo', label: '宁波' },
            { value: 'wenzhou', label: '温州' }
          ]
        }]
      };
    },
    methods: {
      handleRemoveTag(value, index) {
        // value 是被移除节点的值（emitPath 下为完整路径数组）
        const leaf = Array.isArray(value) ? value[value.length - 1] : value;
        this.removed = { text: leaf, index };
      }
    }
  };
</script>
```
